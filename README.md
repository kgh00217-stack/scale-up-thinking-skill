# Scale-Up Thinking Skill (스케일업 스킬)

> AI에게 뭔가를 요청할 때마다, 원래 요청(1배)과 10배·100배로 키운 버전을 같이 제안하는 Claude Code 스킬입니다.

저장소: https://github.com/kgh00217-stack/scale-up-thinking-skill

## Before / After

**설치 전**: 요청한 그대로만 결과가 나옵니다.

```
나: 신입사원 온보딩 자료 만들어줘
Claude: (바로) 온보딩 체크리스트를 작성해드릴게요...
```

**설치 후**: 실행 전에 3가지 크기를 먼저 제안하고, 고른 크기로 작업합니다.

```
나: 신입사원 온보딩 자료 만들어줘

Claude:
🚛 스케일 업 제안

1배: 신입사원 온보딩 체크리스트와 안내 자료 1세트 작성
10배: 부서별 체크리스트 + 90일 적응 로드맵 + 멘토 배정 가이드까지 포함
100배: 전사 온보딩 프로그램 설계 — 직무별 커리큘럼 + 성과 측정 지표 + 6개월 후 정착률 추적 체계

어떤 크기로 할까요?

나: 10배로

Claude: (10배 버전으로 작업 시작)
```

## 왜 필요한가

AI에게 요청할 때 우리는 대부분 "사람이 하던 크기" 그대로 시킨다. 1배로 물으면 1배짜리 답만 온다. 이 스킬은 매번 "이걸 10배, 100배로 키우면 어떻게 될까?"를 먼저 되물어서, 처음엔 떠올리지 못했던 접근을 보여준다. 반대로 반복적인 단순 업무는 0.1배, 0.01배로 줄이라고 되물어서 자동화·템플릿화할 지점을 찾아준다.

## 설치 방법

```bash
git clone https://github.com/kgh00217-stack/scale-up-thinking-skill.git
cp -r scale-up-thinking-skill/scale-up-thinking ~/.claude/skills/
```

Claude Code를 재시작하면 바로 적용됩니다. 별도 설정 없이, 업무/분석/조사/콘텐츠 작성 요청을 하면 자동으로 스케일업 제안이 나옵니다.

## 사용법

- 스케일 선택: 대화 중 "1배", "10배", "100배"라고 숫자만 말하면 그 크기로 진행
- 그냥 원래대로: "그냥 해줘" / "1배로"
- 끄기: "스케일업 끄기" (이후 대화에서는 제안 없이 바로 실행)
- 다시 켜기: "스케일업 다시 켜줘"

## 예시 더 보기

**요청**: "국내 HR SaaS 시장 조사해줘"

- **1배**: 국내 HR SaaS 시장 현황과 주요 플레이어 정리
- **10배**: 시장 규모·성장률·주요 5사 비교 + 다른 시장과의 차이점 분석
- **100배**: 아시아 8개국 HR SaaS 시장 비교 분석 + 시장별 진입 전략 + 포지셔닝 제안서

**요청**: "다음 주 팀 미팅 안건 만들어줘"

- **1배**: 다음 주 팀 미팅 안건 리스트 작성
- **10배**: 지난 4주 미팅 기록 기반 미결 이슈 추적 + 안건 우선순위 제안
- **100배**: 팀 미팅 운영 체계 재설계 — 주간/월간/분기 미팅 구조 + 의사결정 프레임워크

더 많은 예시와 스케일 확장 원칙은 [`scale-up-thinking/SKILL.md`](./scale-up-thinking/SKILL.md)에 있습니다.
